# Project Map

## Purpose

MythicAgeMod is a Fabric Minecraft mod project. The active workstream adds and improves Greek myth creatures with a design-first visual validation process: concept design packages define the intended creature, generated Blockbench/UV/texture previews verify the asset layer, Java models implement in-game geometry, and entity/NBT validation checks registration/schema correctness.

## Main Areas

| Path | Meaning | When to edit | Tests/commands |
| --- | --- | --- | --- |
| `src/main/java/com/example/mythic_age/client/render/entity/model/` | Java entity model geometry and animation. | Edit when changing in-game creature proportions, parts, or animation. | `./gradlew build --offline` |
| `src/main/java/com/example/mythic_age/client/render/entity/` | Entity renderers binding models to textures. | Edit when adding a renderer, changing shadow size, or changing texture path. | `./gradlew build --offline` |
| `src/main/java/com/example/mythic_age/entity/` | Entity classes and registration. | Edit when adding behavior, attributes, dimensions, spawn rules, or entity registration. | `./gradlew build --offline`; `python3 tools/entity_validation_pipeline.py audit` |
| `src/main/java/com/example/mythic_age/client/visual/VisualProbeServer.java` | Optional local HTTP probe for MC screenshots and runtime NBT validation. | Edit only if screenshot/NBT automation behavior changes. Current round skips MC screenshots by user request. | `./gradlew build --offline`; runClient only if user asks |
| `tools/greek_creature_visual_pipeline.py` | Source of truth for generated Greek creature design docs, concept art, `.bbmodel`, UV templates, textures, previews, and visual reports. | Edit this before regenerating Greek visual assets. Avoid hand-editing generated outputs without updating this script. | `python3 tools/greek_creature_visual_pipeline.py all`; `python3 tools/greek_creature_visual_pipeline.py audit` |
| `tools/entity_validation_pipeline.py` | Entity/NBT schema validation generator/auditor. | Edit when entity list, NBT rules, or validation reports change. | `python3 tools/entity_validation_pipeline.py audit` |
| `docs/美术资源/greek_creatures/design/` | Per-creature design packages. Generated from the visual pipeline. | Treat as reviewable design output; update pipeline for durable changes. | `python3 tools/greek_creature_visual_pipeline.py all` |
| `docs/美术资源/greek_creatures/concepts/` | Per-creature concept-design PNGs. Generated from the visual pipeline. | Review before modeling; regenerate from pipeline. | `python3 tools/greek_creature_visual_pipeline.py all` |
| `docs/美术资源/blockbench/greek_creatures/` | Generated Blockbench `.bbmodel` files. | Import/review in Blockbench; update pipeline for durable geometry changes. | `python3 tools/greek_creature_visual_pipeline.py audit` |
| `docs/preview_assets/greek_creatures/` | Generated concept contact sheet, UV previews, texture-fit reports, Blockbench previews, visual report. | Review after generation; do not use stale MC screenshots as current evidence. | `python3 tools/greek_creature_visual_pipeline.py all` |
| `src/main/resources/assets/mythic_age/textures/entity/` | Runtime entity textures. Several Greek textures are generated by the visual pipeline. | Edit via pipeline unless doing a deliberate manual art pass. | `python3 tools/greek_creature_visual_pipeline.py audit`; `./gradlew build --offline` |

## Data And Control Flow

For Greek creature visual work:

1. Update `tools/greek_creature_visual_pipeline.py` creature definitions, signature features, geometry, UVs, or texture rules.
2. Run `python3 tools/greek_creature_visual_pipeline.py all`.
3. Review `docs/preview_assets/greek_creatures/concept_design_contact_sheet.png` before treating modeling as acceptable.
4. Review `docs/preview_assets/greek_creatures/blockbench_validation_contact_sheet.png` and `texture_fit_report.json` for asset-layer issues.
5. Sync Java model files under `src/main/java/com/example/mythic_age/client/render/entity/model/` when in-game geometry differs from the generated Blockbench intent.
6. Run `./gradlew build --offline`.
7. Run `python3 tools/entity_validation_pipeline.py audit` for registration/NBT checks.
8. Do not launch MC visual screenshots unless the user explicitly asks again; current instruction says they are not needed.
