# 任务1 - 设计文档

## 目标

把行走树根系从“中心聚团的底座感”重构为“沿根环向外舒展的树根感”，并且在正面、45 度和侧面都能成立。

## 当前问题

- 根颈太厚，中心块在正面占据了过多画面。
- 前方和左右根的起点虽然数值上外移了，但视觉上仍被中心根团吃掉，第一眼还是像一圈围着树干的块。
- 薄过渡环与中心根团一起形成了完整平台边，削弱了树根“从树干分叉出去”的读感。
- 部分主根的角度实际是向内收的，导致截图里看起来像根尖往树干底部扎回去。
- 主根底部过低，挤占了原本应该留给细根/根须的一格空间。
- 树干与外圈根之间缺少连续的连接根/板根，看起来像树干和根须是两套分离结构。
- 树干本体偏细，和当前古树体量不匹配。

## 设计决策

### 1. 根颈

- 根颈只保留窄树干外扩，不再保留会形成“平台边”的大面积前后左右横条。
- 根颈目标宽度控制在树干宽度的约 2 倍以内。
- 根颈只负责连接树干与根，不负责充当外轮廓。

### 2. 主根布局

- 主根的 pivot 固定分布在外围一圈，不能再集中在中心半径 `8` 内。
- 主根固定为 13 根：
  - 前方 4 根
  - 左侧 3 根
  - 右侧 3 根
  - 后方 3 根
- 正面布局必须保留中间留白，左右外张更强，内侧根更细更短。

### 3. 分层

- 主根：粗、长、角度大，是外轮廓主体。
- 次根：在主根之间补少量层次，宽度小于主根，不得遮住主根边界。
- 垂根：只保留少量，且尽量不放在正面中轴线上。

### 3.1 连接逻辑

- 在树干底部与外圈主根之间增加连接根/板根。
- 连接根必须从树干根颈区域出发，再向外下方过渡到主根层，不能只在底部悬着。
- 正面和 45 度视角都必须能看出“树干 -> 连接根 -> 主根 -> 根须”这条连续关系。

### 4. 动画兼容

- 隐藏移动腿保留，但继续缩小并上移，让它们在前视图几乎不可见。
- 不修改实体属性、碰撞箱、变体逻辑、渲染路径。

### 5. 离地结构

- 主根和根环形成的主体底部需要整体抬高。
- 最低一格视觉空间留给细根/根须，让它们作为实体结构的一部分垂到接近地面。
- 根须不能从中心往内垂，必须从外环或主根下缘向外下方垂出。

### 6. 树干体量

- 树干宽度需要显著大于普通 Minecraft 树木主干。
- 树干下半部应有额外增厚，保证和根部连接时不会显得细长、悬空。

## 数据流

1. 修改 `WalkingTreeModel#getTexturedModelData()` 中根颈与根系部件参数。
2. 按相同参数同步 `docs/美术资源/blockbench/walking_tree.bbmodel`。
3. 对 `.bbmodel` 做 pivot 分布、旋转后包络与 UV 审计。
4. 编译验证通过后启动客户端实测。

## 关键伪代码

```text
shrink root collar
remove platform-like ring silhouette

for each major root in front/left/right/back ring:
  place pivot on outer ring
  use larger outward angle
  keep center line open in front view

add a few thinner secondary roots between major roots
add only a few hanging roots near sides/back

sync bbmodel from Java geometry source
audit uv overflow + rotated root bounds + pivot spread
build and run client
```
