## ✨ 特性概览

### 📜 神力证明系统 (NEW!)
- **渐进式解锁**: 与神殿守护者对话开启神力证明收集功能
- **多文明获取方式**: 每个神话文明都有独特的神力证明获得方式
  - **希腊文明**: 矿物/贵重物品兑换 (钻石×3倍率, 金×2倍率, 铁×1倍率)
  - **埃及文明**: 神像基座系统 (7等级神像, 金锭兑换, 周期性产出)
  - **北欧文明**: 怪物掉落 (概率掉落, 不同怪物不同倍率)
  - **中国文明**: 村庄人口数量 (每20村民产出1证明/分钟)
- **经济平衡**: 不同文明的获取难度和产出平衡

### 🔮 神力法术书系统
- 4种不同文明的神力法术
- 智能目标选择和射线检测
- 平衡的冷却机制
- 丰富的视觉和音效反馈

### 🏺 圣物系统
- 5种传说中的神话圣物
- 三层效果系统：手持、被动、神殿
- 范围性增益效果
- 资源生成和经验加成

### 🏛️ 神殿多方块结构
- 可建造的神殿结构
- 圣物激活系统
- 区域性增益效果

### 🐂 神话生物
- 米诺陶实体
- 智能AI行为
- 冲锋攻击能力
- 完整的音效系统

## 🔧 安装指南

### 前置要求
- Minecraft 1.20.1
- Fabric Loader 0.14.21+
- Fabric API

### 安装步骤
1. 下载并安装 [Fabric Loader](https://fabricmc.net/use/)
2. 下载 [Fabric API](https://modrinth.com/mod/fabric-api)
3. 将 Mod 文件放入 `.minecraft/mods` 文件夹
4. 启动游戏并享受神话体验！

## 🛠️ 开发和编译

### 编译要求
- Java 17 或更高版本
- Gradle 8.2 或项目 Gradle Wrapper；如使用本地 Gradle，可通过 `GRADLE_HOME` 或 `GRADLE_BIN` 指定路径

### 快速编译
```bash
# 使用项目提供的编译脚本
./build-with-gradle8.sh build

# 清理后重新编译
./build-with-gradle8.sh clean build
```

### 详细编译指南
查看 [GRADLE_SETUP.md](GRADLE_SETUP.md) 获取完整的编译配置和故障排除信息。

### 编译输出
成功编译后，Mod文件将生成在 `build/libs/mythic_age-1.0.0.jar`

## 🔮 神力法术书系统

### 闪电风暴法术书 (宙斯)
- **效果**: 以玩家为中心启动持续60秒的闪电风暴，控制天气并攻击所有非玩家生物
- **冷却**: 6秒
- **类型**: 攻击法术
- **风暴范围**: 50格半径
- **持续时间**: 60秒（1200 ticks）
- **闪电间隔**: 每3秒一轮攻击
- **命中概率**: 75%概率击中并杀死生物
- **天气控制**: 开始时下雨+雷暴，结束时恢复晴天
- **使用**: 右键点击即可在玩家位置启动风暴

#### 闪电风暴系统详解
**风暴启动**:
- 自动改变天气为雨天+雷暴
- 在空中生成大量雷云效果
- 初始闪电展示（5道装饰性闪电）

**生物攻击机制**:
- **搜索范围**: 50格半径内的所有非玩家生物
- **攻击频率**: 每3秒搜索并攻击一次
- **命中判定**: 每个生物75%概率被选中攻击
- **伤害机制**: 闪电直接杀死目标生物

**天气系统**:
- **风暴期间**: 强制雨天+雷暴效果
- **风暴结束**: 自动恢复晴天，持续5分钟
- **视觉效果**: 高空雷云聚集和散去动画

**特殊效果**:
- 如果范围内无生物，会产生装饰性闪电
- 被击中生物位置会产生灵魂粒子效果

### 复原术法术书 (雅典娜)

### 动物招引法术书 (波塞冬)
- **效果**: 在目标位置建造动物招引塔，持续吸引动物并促进草地生长
- **冷却**: 5秒

- **持续时间**: 5分钟（6000 ticks）
- **吸引范围**: 20格内的被动动物
- **草地生长**: 5格范围内促进草和草方块生长
- **使用**: 右键点击目标地面位置建造招引塔

#### 动物招引塔系统详解
**建造要求**:
- 目标位置必须有5层垂直空间
- 地面必须有十字形区域的实体方块支撑

**塔结构** (以玩家面向北方建造为例):
```
    [苔石]           ← 第5层 (顶层装饰，中心位置)
  苔石 苔石 苔石      ← 第4层 (十字形苔石)
    苔石
苔石 苔石 苔石      ← 第3层 (核心在靠近玩家的位置)
  [招引核心] ← 三叉戟纹理面朝向玩家(南)，发光
  苔石 苔石 苔石      ← 第2层 (十字形苔石)  
    苔石
  苔石 苔石 苔石      ← 第1层 (十字形苔石基础)
    苔石
```

**功能特性**:
- **动物吸引**: 每30秒自动吸引20格范围内的所有被动动物
- **草地生长**: 每10秒在5格范围内随机生长草和草方块（30%概率）
- **自动清理**: 5分钟后自动消失，避免世界污染
- **视觉效果**: 周期性粒子效果和音效反馈

#### 丰饶祭坛系统详解
**建造要求**:
- 需要11×11×10的空间（121格×10层）
- 目标位置下方需要足够的地面支撑
- 周围16格范围无障碍物影响

**祭坛结构** (10层设计):
```
第十层 (y+9):  3×5 半砖柱顶部
第九层 (y+8):  5×5 半砖平台  
第八层 (y+7):  符文墙壁层
第七层 (y+6):  核心层 (包含丰饶祭坛核心)
第六层 (y+5):  5×5 墙壁框架
第五层 (y+4):  11×11 金线砖平台
第四层 (y+3):  符文装饰层
第三层 (y+2):  储藏室层 (矿物/食物/木材)
第二层 (y+1):  墙壁和柱子框架  
第一层 (y+0):  11×11 基础层
```

**方块类型说明**:
- **A类型**: 丰饶祭坛砖(上下前后带金线) - 基础边框
- **B类型**: 丰饶祭坛柱子 - 结构支撑
- **C类型**: 丰饶祭坛墙壁(不带符文) - 基础墙体
- **D类型**: 丰饶祭坛墙壁(下方带符文) - 装饰墙体
- **E类型**: 丰饶祭坛砖(前后左右带金线) - 平台层
- **F类型**: 丰饶祭坛砖(不带金线) - 内部填充
- **G类型**: 丰饶祭坛半砖 - 顶部装饰
- **H类型**: 储藏室(矿物) - 资源展示
- **I类型**: 储藏室(食物) - 资源展示
- **J类型**: 储藏室(木材) - 资源展示
- **K类型**: 丰饶祭坛墙壁(上方带符文) - 高级装饰
- **O类型**: 丰饶祭坛核心 - 功能核心
- **Z类型**: 丰饶祭坛砖(转角金线) - 特殊装饰

**资源生成系统**:
- **生成间隔**: 30-60秒随机间隔
- **生成位置**: 第一层祭坛砖上方空气位置
- **智能定位**: 避免覆盖现有方块
- **生成范围**: 祭坛第一层11×11区域

**生成概率分布**:
- **35%**: 一堆肉方块 (包含24-36个随机肉类)
- **30%**: 一堆木头方块 (包含24-36个随机木材)
- **25%**: 矿物方块 (铁块、金块、钻石块等)
- **10%**: 珍贵方块 (下界合金块、信标、附魔台等)

**结构验证**:
- 核心位于第七层中心位置
- 第一层必须为A+F类型方块组合
- 第五层必须为完整的E类型方块层
- 关键柱子位置必须为B类型方块
- 储藏室必须在第三层指定位置

**视觉特效**:
- 核心方块发光 (亮度等级10)
- 储藏室发光 (亮度等级3)
- 符文墙壁发光 (亮度等级5)
- 定期粒子效果和音效反馈
- 资源生成时的金色粒子爆炸

**交互功能**:
- 右键点击核心方块查看祭坛状态
- 显示结构完整性信息
- 显示下次资源生成时间
- 结构破坏时的提示信息

## 📜 神力证明系统详解

### 系统概述
神力证明是通往神话力量的钥匙，每个文明都有独特的获取方式，体现了不同文化的特色。

### 开启流程
1. **发现神殿**: 在世界中找到任意文明的神殿
2. **与守护者对话**: 右键点击神殿守护者
3. **激活系统**: 守护者会开启你的神力证明收集功能
4. **获得指南**: 收到一本"神力证明指南"，包含详细说明

### 希腊文明：贸易兑换
**获取方式**: 与希腊神殿守护者用矿物/贵重物品兑换

**兑换比率**:
- 钻石系列: ×3 倍率 (1钻石 = 3证明)
- 金系列: ×2 倍率 (1金锭 = 2证明)  
- 铁系列: ×1 倍率 (1铁锭 = 1证明)
- 绿宝石: ×5 倍率 (1绿宝石 = 5证明)
- 下界合金: ×5 倍率 (1下界合金 = 5证明)

**使用方法**: 手持物品与希腊神殿守护者右键交互

### 埃及文明：神像基座系统
**获取方式**: 神像基座周期性自动产出

**神像等级** (按产出效率排序):
1. **奴隶神像**: 1个/2分钟 (成本: 5金锭)
2. **市民神像**: 2个/2分钟 (成本: 10金锭)
3. **士兵神像**: 3个/2分钟 (成本: 20金锭)
4. **王后神像**: 5个/1.5分钟 (成本: 35金锭)
5. **国王神像**: 7个/1.5分钟 (成本: 50金锭)
6. **王室夫妇神像**: 12个/1分钟 (成本: 80金锭)
7. **法老神像**: 20个/1分钟 (成本: 120金锭)

**使用方法**:
1. 与埃及神殿守护者用金锭兑换神像
2. 将神像放置在埃及神像基座上
3. 神像开始自动产出神力证明

### 北欧文明：战斗掉落
**获取方式**: 击杀怪物有概率掉落

**掉落概率**:
- 普通怪物 (僵尸、骷髅): 5% 概率, 1个
- 中等怪物 (爬行者、蜘蛛): 8% 概率, 1个
- 稀有怪物 (末影人、女巫): 15% 概率, 2个
- 精英怪物 (凋灵骷髅、烈焰人): 20% 概率, 3个
- BOSS级怪物:
  - 凋灵: 100% 概率, 30个
  - 末影龙: 100% 概率, 50个

### 中国文明：人口繁荣
**获取方式**: 基于村庄人口数量周期性产出

**产出机制**:
- 基础产出: 每20个村民产出1个证明/分钟
- 概率奖励: 剩余人口提供额外概率 (剩余人口×5%概率)
- 产出位置: 村庄中心附近

**示例**:
- 25村民 = 1个固定 + 25%概率额外1个
- 50村民 = 2个固定 + 50%概率额外1个  
- 100村民 = 5个固定/分钟

**发展策略**: 保护和发展村庄，增加村民数量
