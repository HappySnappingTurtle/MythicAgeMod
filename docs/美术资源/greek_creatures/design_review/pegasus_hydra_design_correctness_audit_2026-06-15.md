# Pegasus / Hydra 设计正确性审查（2026-06-15）

## 结论

当前已实现的 `pegasus` 和 `hydra` 设计不正确，不能继续建模、贴图、动作或 Java 同步。

V3 蓝图和技术设计图只代表新的候选方向，不代表已经通过。进一步复核后确认：当前 V3 设计图仍偏结构示意，不能单独证明“天马一定不会头大/不像马”或“九头蛇每个头颈一定接上身体”。它们现在的状态是：`needs_user_review` / `candidate_needs_user_review` / `direction_correct_but_detail_insufficient`。在比例/拓扑锁定表与新审批图确认前，`modeling_allowed=false` 必须保持不变。

## 天马审查

### 旧设计错误

- 侧面不是马的比例：头颈呈竖直塔状，身体被简化成横向方块，翼片像平铺长条。
- 头部问题不是单纯“大一点或小一点”，而是马头、吻部、颈部、肩胛的关系没有先成立。
- 翅膀和骑乘空间没有建立在正确的马体上；继续调尺寸只会在错误轮廓上返工。
- 纯白贴图缺少足够的浅灰结构面时，会在渲染中显得空白。

### V3 候选设计是否方向正确

方向基本正确，但细节不足，不能放行建模。

正确点：

- 把“侧面先读成白马”作为最高优先级。
- 规定头部应小而细长，吻部要前伸，不能用大方头补细节。
- 规定颈部从鬐甲/肩胛斜向前上方伸出，禁止竖直白柱。
- 规定翼根在肩后，骑乘空间在背中部，不能互相遮挡。
- 规定纯白材质必须有眼、鼻孔、嘴线、鬃毛、蹄和浅灰分面。

还必须确认：

- 用户是否认可 `docs/美术资源/greek_creatures/design_sheets/pegasus_v3_design_sheet.svg` 的比例方向。
- 用户是否认可 `docs/美术资源/greek_creatures/design_sheets/pegasus_v3_proportion_lock.md` 中的原版马式比例锁定。
- 马头是否以“接近原版马的细长头颈”为准，而不是再做大头可爱化。
- 翅膀展开宽度是否以可读羽毛层级优先，而不是水平白条。
- 需要新增头部/吻部、颈根、翼根、骑乘空间放大确认图；没有这些放大图不进入 Blockbench。

### 设计通过条件

- 侧面不看标签也能认出白马。
- 头部比例匹配身体，头不是大玩具头，也不是看不见。
- 颈部斜向连接肩胛，不能竖直插在背上。
- 翼根、骑乘点、马头互不遮挡。
- 纯白身体有清楚结构阴影，不像空白贴图。

## 九头蛇审查

### 旧设计错误

- 旧三分之四视角呈现为方块头墙和臃肿前身，怪物身份不清。
- 多个头没有可靠的头-颈-肩连接；头和身体关系像拼接件，不像从同一肩带生长。
- 身体没有低伏长身和长尾的压迫感，局部方块体量掩盖了蛇形结构。
- 头部数量、头部错层和颈根 socket 没有在建模前固定。

### V3 候选设计是否方向正确

方向基本正确，但细节不足，不能放行建模。

正确点：

- 默认改为显性九头，符合“九头蛇”的中文直觉。
- 规定每条颈至少有 `neck_root`、`neck_mid`、`neck_tip`，并与 `neck_socket` 实体重叠。
- 规定低伏长身、肩带承托、长尾和背脊鳞，不再让躯干成为大箱体。
- 规定每个头都有眼、上下颚、嘴线、獠牙和角/毒腺，细节不靠放大头部实现。
- 规定 45 度必须看出九头错层，不能糊成一堵墙。

还必须确认：

- 用户是否认可 `docs/美术资源/greek_creatures/design_sheets/hydra_v3_design_sheet.svg` 的九头默认方案。
- 用户是否认可 `docs/美术资源/greek_creatures/design_sheets/hydra_v3_topology_lock.md` 中的九头 socket 拓扑。
- 是否保持九个头作为 1.0 设计；若为了 MC 可读性减少头数，必须在设计阶段先明确，不允许建模后再改。
- 每个头的大小要依附颈根和肩带比例，不能再用大头弥补五官。
- 需要新增单头-颈段-肩带 socket 放大图；没有这些放大图不进入 Blockbench。

### 设计通过条件

- 正面能读出九头扇形，而不是一排方块。
- 45 度能同时看到头、颈根、肩带、低伏身体和长尾。
- 每个头都有实体颈段连接到 shoulder socket。
- 身体低而长，头部大小匹配身体，不再头身断裂。
- 每个头都有眼、嘴、牙或毒性细节。

- 不再基于旧 `.bbmodel` 或旧 Java model 推回设计。
- 先让用户确认设计图的比例和轮廓，再进入 Blockbench。
- 对任何“头大、头小、没连接、看不出特征”的反馈，先回设计包，不直接调模型。

## 建模解锁条件

只有同时满足以下条件，才允许对 `pegasus` 或 `hydra` 重新建模：

1. 对应 V3 蓝图中的 `design_status` 改为 `approved_for_modeling`。
2. 对应 V3 蓝图中的 `design_correctness_verdict` 改为 `approved_for_modeling`。
3. 对应 V3 蓝图中的 `design_detail_sheet_status` 改为 `approved_for_modeling`。
4. 对应 V3 蓝图中的 `modeling_allowed` 改为 `true`。
5. 对应 V3 蓝图中的 `design_sheet_status` 改为 `approved_for_modeling`。
6. 技术设计图和细化锁定表存在，且与蓝图比例、部件和 UV 计划一致。
7. `tools/greek_design_first_gate.py audit` 通过。
