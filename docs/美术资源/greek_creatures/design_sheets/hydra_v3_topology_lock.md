# Hydra / 九头蛇 V3 拓扑锁定表

状态：`draft_requires_user_approval`

用途：本文件用于阻止继续按断颈、头身不连或臃肿躯干的九头蛇方案建模。它必须在 `.bbmodel`、Java model、贴图和动作重建前被确认。

## 当前设计判断

旧九头蛇实现不正确。主要错误是多头拓扑没有成立：头、颈、肩带和身体之间缺少真实体积连接，躯干过于臃肿，头部与身体比例不稳定。

V3 必须先成立“低伏长身 + 九条颈从同一肩带 socket 生长 + 每个蛇头都与颈段重叠连接”的结构，再追求贴图、动作和攻击表现。

## 不可变拓扑

| 项 | 锁定要求 | 否决条件 |
| --- | --- | --- |
| 头数 | 默认 9 头；如果改 5 头，必须先改设计包 | 建模后临时减少或增加头数 |
| 身体 | 低伏长身，长度约为整体高度的 `3.0` 到 `4.0` 倍 | 正面主视觉是大箱体或胖蜥蜴 |
| 肩带 | `shoulder_saddle` 横向承载 9 个 socket | 颈根从空中、背面贴图或单点长出 |
| 颈根 | 每个 `neck_root` 与对应 socket 几何重叠 | 头和身体没有接触，或只靠命名连接 |
| 颈段 | 每条颈至少 `neck_root`、`neck_mid`、`neck_tip` 三段 | 只有一根直柱，无法表现弯曲 |
| 头部 | 楔形蛇头，中央头可略大但不超过相邻头 `1.18` 倍 | 大方头墙，或小绿块没有五官 |
| 头颈连接 | `neck_tip` 必须与 `head_core` 重叠 | 头悬空、头贴在颈段末端但不接触 |
| 尾巴 | 长尾从身体后方逐段变细 | 尾巴短小，无法拉出蛇形轮廓 |

| 编号 | 命名 | 位置 | 高度/方向 | 连接要求 |
| --- | --- | --- | --- | --- |
| 01 | `head_01_center` | 肩带中央 | 最高，略前探 | 中央 socket 与中央颈根重叠 |
| 02 | `head_02_inner_left` | 中央左侧 | 略低于 01 | 向左前上弯曲 |
| 03 | `head_03_inner_right` | 中央右侧 | 略低于 01 | 向右前上弯曲 |
| 04 | `head_04_mid_left` | 左中侧 | 中高 | 与 02 错层，不能贴成墙 |
| 05 | `head_05_mid_right` | 右中侧 | 中高 | 与 03 错层，不能贴成墙 |
| 06 | `head_06_outer_left` | 左外侧 | 中低，向外张开 | 外侧颈根仍必须落在肩带上 |

## 每个头的最低细节

- `head_core`：楔形蛇头主体。
- `upper_jaw` / `lower_jaw`：上下颚分离，侧面可读。
- `left_eye` / `right_eye`：亮黄或黄绿高对比眼点。
- `mouth_line`：深色嘴线，不能和身体绿混在一起。
- `left_fang` / `right_fang`：每头至少正面或侧面能读出獠牙。
- `horns` 或 `poison_glands`：每头至少一种额外神话特征。

## 三视图建模锚点

### 正面

- 九个头呈扇形，头与头之间留出间隙。
- 每个 socket 必须可见或可通过肩带阴影读出。
- 正面身体只能承托多头，不能成为最大视觉块。

### 侧面

- 身体低、长、尾巴长。
- 至少看到中央颈、近侧三条颈和远侧错层颈影。
- 颈不能竖直插在背上，要从肩带向前上弯。

### 45 度

- 这是最终结构验收角。
- 必须同时看到九头错层、socket、颈根、低伏身体、背脊鳞、长尾。
- 每个可见头都要有眼、嘴、牙或毒腺；细节不能靠放大头部。

## 当前结论

当前设计仍为 `draft_requires_user_approval`。在本文件确认前，任何九头蛇重建都应视为违规返工风险。
