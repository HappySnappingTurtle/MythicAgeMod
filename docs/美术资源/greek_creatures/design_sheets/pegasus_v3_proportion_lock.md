# Pegasus / 天马 V3 比例锁定表

状态：`draft_requires_user_approval`

用途：本文件用于阻止继续按错误天马比例建模。它必须在 `.bbmodel`、Java model、贴图和动作重建前被确认。

## 当前设计判断

旧天马实现不正确。主要错误不是贴图或局部块体，而是基础马体比例没有成立：头部偏大或不可读、颈部关系不稳定、翼根和骑乘空间建立在错误轮廓上。

V3 必须以原版成年马的可读比例为基准：先是一匹横向长身、头颈自然前伸的纯白马，再是带翼、可飞行、可骑乘飞行的神话单位。

## 不可变比例

| 项 | 锁定要求 | 否决条件 |
| --- | --- | --- |
| 主躯干 | 横向长条马体，长度约为躯干高度的 `1.8` 到 `2.2` 倍 | 身体短胖，像箱体或狗形 |
| 胸腔/臀部 | 胸腔略深，臀部后收，背线接近水平 | 胸和臀被合成一个无结构方块 |
| 头部 | 细长马头，头宽约为身体宽度的 `0.35` 到 `0.45` | 大方头、玩具头、头比胸还抢视觉 |
| 吻部 | 向前伸出，长度约为头核心的 `0.55` 到 `0.75` | 没有吻部，或嘴鼻只靠贴图暗示 |
| 颈部 | 从鬐甲/肩胛斜向前上方伸出，至少两段 | 竖直白柱，或头直接插在背上 |
| 腿 | 四腿分上腿、小腿、蹄，马蹄可读 | 四根白柱，没有关节和蹄 |
| 翼根 | 左右翼根在肩后，不能挂在腹部、臀部或背中央 | 翼片像水平白条，遮住头颈 |
| 骑乘空间 | 在背中部，位于翼根后内侧，玩家不遮挡头颈 | 骑乘点挤压翼根或盖住头部 |

## 三视图建模锚点

### 侧面

- 侧面是最高优先级；必须先读成白马。
- 头部中心必须在胸腔前方，而不是在身体上方。
- 颈根锚点为 `withers_anchor`，位于胸腔上缘后 20% 到 35% 区间。
- `neck_lower` 从 `withers_anchor` 前上斜出，`neck_upper` 再接 `head_core`。
- 翼根 `left/right_shoulder_joint` 位于肩胛后方，不能压过颈根。

### 正面

- 胸部窄，头部、两耳、两眼必须可见。
- 翅膀在肩后打开，不能把头部挡成白块。
- 身体纯白但必须有浅灰分面，不允许大面积空白。

### 45 度

- 同时看到头、颈、背、翼根、骑乘空间、四肢和尾鬃。
- 近侧翼可以大，但不能遮住头颈连接。
- 头部要小而清楚，细节来自眼、鼻、嘴、吻部、耳，不来自放大头。

## 必须建出的细节

- `head_core`：马头主体，偏长，不是正方体。
- `muzzle`：独立前伸吻部，带鼻孔和嘴线。
- `left_eye` / `right_eye`：小而高对比，落在头部前上侧。
- `left_ear` / `right_ear`：耳朵高但不夸张。
- `neck_mane_strip`：沿颈背的鬃毛条，用浅灰分段。
- `body_barrel`、`chest`、`rump`：三者必须能在贴图和模型上分辨。
- `primary_feathers_01_06`：每侧至少六片主羽，羽毛边界明确。
- `tail_plume_segments`：尾鬃从臀部后上方接出。

## 建模解锁检查

- [ ] 用户确认本比例锁定表。
- [ ] 用户确认天马仍以“原版马式比例”为优先，不接受大头化。
- [ ] 新审批图需要包含头部/吻部放大框、翼根位置框、骑乘空间框。
- [ ] 新 `.bbmodel` 每个关键部件命名必须与蓝图一致。
- [ ] Blockbench 三视图必须验证头部比例、颈根斜向连接和翼根位置。

当前设计仍为 `draft_requires_user_approval`。在本文件确认前，任何天马重建都应视为违规返工风险。
