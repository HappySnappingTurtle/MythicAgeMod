## 五、技术规范

### 5.1 纹理规范
- **格式**：PNG格式，支持透明通道
- **尺寸**：必须为2的幂次方（8x8, 16x16, 32x32, 64x64, 128x128等）
- **颜色深度**：32位RGBA
- **压缩**：无损压缩
- **命名规范**：小写字母，下划线分隔，英文命名

### 5.2 模型规范
- **格式**：JSON格式，符合Minecraft模型标准
- **纹理引用**：相对路径引用对应纹理文件
- **动画**：支持基础动画，如旋转、缩放、移动
- **优化**：模型面数控制在合理范围内，避免性能问题

### 5.3 音效规范
- **格式**：OGG Vorbis格式
- **采样率**：44.1kHz
- **比特率**：128-192 kbps
- **声道**：单声道或立体声
- **音量**：标准化处理，避免音量过大或过小

### 5.4 文件组织
```
assets/mythic_age/
├── textures/
│   ├── item/
│   │   ├── spellbook/          # 法术书纹理
│   │   └── god_power/          # 神力相关物品纹理
│   ├── entity/                 # 实体纹理
│   ├── particle/               # 粒子效果纹理
│   └── gui/                    # GUI界面纹理
├── models/
│   ├── item/                   # 物品模型
│   └── entity/                 # 实体模型
├── sounds/
│   └── god_power/              # 神力音效
└── lang/                       # 本地化文件
```

## 七、质量标准

### 7.1 视觉质量
- 纹理清晰，无模糊或锯齿
- 颜色搭配协调，符合文明特色
- 风格统一，与游戏整体美术风格匹配

### 7.2 技术质量
- 文件大小合理，不影响游戏性能
- 格式标准，兼容性良好
- 命名规范，便于管理和维护

### 7.3 文化准确性
- 设计元素符合对应文明的历史文化背景
- 避免文化刻板印象和不当表现
- 尊重原始文化，体现文明特色
