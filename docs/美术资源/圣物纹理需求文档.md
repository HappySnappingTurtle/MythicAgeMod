# 神话时代MOD - 圣物纹理需求文档

## 项目背景

本文档为《神话时代MOD》(MythicAge Mod) 的圣物系统纹理设计需求。该MOD基于Minecraft 1.20.1 Fabric平台开发，旨在重现微软经典RTS游戏《神话时代：重制版》的神话元素和游戏机制。

### 核心概念
- **圣物系统**：玩家可收集的稀有神话物品，具有强大的魔法效果
- **三层效果机制**：手持效果、背包被动效果、神殿全局效果
- **文明特色**：每个文明的圣物都体现其独特的神话背景和文化特征
- **游戏平衡**：不同稀有度的圣物提供不同强度的增益效果

## 中国文明圣物需求

### 1. 昆仑镜 (Kunlun Mirror)
**神话背景**：传说中西王母的神器，能够洞察万物本质，预知未来
**物品描述**：古老的青铜镜面，镜背雕刻着昆仑山脉和仙鹤图案
**视觉要求**：
- 主体：圆形青铜镜，直径占纹理70%
- 镜面：略带神秘蓝光的反射效果
- 镜背：精细的山脉纹路和飞翔的仙鹤剪影
- 边框：传统中式云纹装饰
- 色调：青铜色主体，蓝色神光点缀
- 风格：古典中国风，神秘而庄重

### 2. 龙珠 (Dragon Pearl)
**神话背景**：东海龙王的至宝，蕴含着无穷的水之力量
**物品描述**：散发着柔和光芒的珍珠，内部似有龙影游动
**视觉要求**：
- 主体：完美的球形珍珠，占纹理80%
- 表面：珍珠光泽，带有彩虹般的反光
- 内部：隐约可见的龙形阴影或光影
- 光效：周围有淡蓝色的水波纹光环
- 色调：珍珠白主体，蓝色水系光效
- 风格：神秘华贵，带有东方龙的威严

### 3. 凤凰羽毛 (Phoenix Feather)
**神话背景**：不死鸟凤凰的尾羽，象征重生与永恒
**物品描述**：燃烧着永不熄灭火焰的金红色羽毛
**视觉要求**：
- 主体：优雅的羽毛形状，占纹理全部
- 羽轴：金色，带有细腻的纹理
- 羽片：渐变的金红色，边缘有火焰效果
- 光效：羽毛周围有橙红色火焰粒子
- 色调：金色到红色的渐变，橙色火光
- 风格：华丽神圣，充满生命力

### 4. 太极八卦盘 (Taiji Bagua Disc)
**神话背景**：道家至宝，蕴含天地阴阳之理
**物品描述**：刻有太极图和八卦符号的玉石圆盘
**视觉要求**：
- 主体：圆形玉盘，直径占纹理75%
- 中心：经典的太极阴阳图案
- 外圈：八个卦象符号均匀分布
- 材质：温润的白玉质感
- 光效：淡淡的白色仙气环绕
- 色调：白玉色主体，黑色阴阳图案
- 风格：庄重神秘，体现道家哲学

## 技术规格要求

### 基础规格
- **分辨率**：32x32像素 (标准Minecraft物品纹理)
- **格式**：PNG格式，支持透明通道
- **色彩**：RGB色彩空间，避免过于鲜艳的颜色
- **风格**：与Minecraft原版美术风格保持一致

### 设计原则
1. **可识别性**：在32x32像素下仍能清晰识别物品特征
2. **文化准确性**：准确反映各文明的神话元素和文化特色
3. **游戏适配性**：与Minecraft的像素艺术风格协调
4. **稀有度体现**：通过光效和细节体现圣物的珍贵性

### 光效处理
- 使用半透明像素创建光晕效果
- 避免过于复杂的光效，保持简洁
- 光效颜色应与圣物的神话属性相符

### 文件命名规范
- 中国圣物：`relic_chinese_[name].png`
- 埃及圣物：`relic_egyptian_[name].png`  
- 北欧圣物：`relic_nordic_[name].png`
