# 神殿守护者纹理设计需求与背景文档

## 📋 项目概述

### 文档目的
本文档为神话时代Mod中各文明神殿守护者的纹理设计提供详细的需求说明、文化背景和技术规范。神殿守护者是神话村庄系统的核心NPC，负责神力证明交易、法术书兑换和神话知识传授。

### 项目背景
神话时代Mod包含5个古代文明的神话体系：希腊、埃及、中国、亚特兰蒂斯和北欧。每个文明都有独特的神殿守护者，他们不仅是功能性NPC，更是文明文化的代表者。通过视觉设计，玩家应该能够立即识别出守护者所属的文明，并感受到相应的文化氛围。

## 🎯 设计目标

### 主要目标
1. **文明识别性**：每个守护者必须具有明确的文明特征
2. **文化准确性**：设计元素应忠实反映对应文明的历史文化
3. **游戏适配性**：纹理必须与Minecraft风格和谐统一
4. **功能区分性**：不同文明的守护者应易于区分
5. **视觉吸引力**：设计应具有美感和神秘感

### 设计原则
- **历史真实性**：基于真实的古代文明服饰和装饰
- **神话元素**：融入相应文明的神话符号和元素
- **现代适应**：在保持古典风格的同时适应现代游戏审美
- **像素艺术**：符合Minecraft的像素艺术风格

## 🏛️ 各文明神殿守护者详细设计需求

### 1. 希腊神殿守护者 (Greek Temple Guardian)

#### 文化背景
古希腊是西方文明的摇篮，以哲学、艺术和民主制度著称。希腊神话中的神明具有人性化特征，智慧女神雅典娜是知识和战略的象征。希腊神殿守护者应体现古典时期的学者形象。

#### 设计要求
**文件名**: `temple_guardian_greek.png`  
**基础模型**: Minecraft村民图书管理员  
**尺寸规格**: 64x64像素PNG格式

**颜色主题**:
- **主色调**: 皇家蓝 (#4169E1) - 象征智慧和高贵
- **辅助色**: 金色 (#FFD700) - 象征神圣和权威
- **点缀色**: 白色 (#FFFFFF) - 象征纯洁和真理

**服装设计**:
- **上身**: 深蓝色希腊式长袍(Chiton)，领口和袖口有金色几何图案装饰
- **腰带**: 金色编织腰带，带有希腊回纹(Greek Key)图案
- **披肩**: 浅蓝色披肩(Himation)，边缘有月桂叶图案

**头部设计**:
- **头饰**: 金色月桂叶冠，象征智慧和胜利
- **发型**: 银白色卷发，体现哲学家的智者形象
- **胡须**: 整齐的白色胡须，增加威严感

**装饰元素**:
- **胸前**: 雅典娜的猫头鹰徽章(金色)
- **袖口**: 古希腊柱式装饰图案
- **手持物**: 古代羊皮纸卷轴，上有希腊文字
- **项链**: 简约的金色链条，悬挂小型智慧女神吊坠

**特殊细节**:
- 眼部应显得睿智而深邃
- 整体姿态优雅而庄重
- 纹理应体现大理石雕塑的质感

### 2. 埃及神殿守护者 (Egyptian Temple Guardian)

#### 文化背景
古埃及文明以其神秘的宗教体系、壮观的金字塔和复杂的象形文字而闻名。法老被视为神在人间的代表，祭司阶层掌握着知识和权力。埃及神殿守护者应体现古王国时期的祭司形象。

#### 设计要求
**文件名**: `temple_guardian_egyptian.png`

**颜色主题**:
- **主色调**: 沙漠金 (#DAA520) - 象征沙漠和太阳
- **辅助色**: 尼罗河蓝 (#20B2AA) - 象征生命之源
- **点缀色**: 法老金 (#FFD700) - 象征权力和永恒

**服装设计**:
- **上身**: 白色亚麻长袍(Kalasiris)，象征纯洁
- **装饰带**: 金色和蓝色相间的装饰带，缠绕在腰间和肩部
- **护胸**: 金色宽领项圈(Wesekh)，镶嵌蓝色宝石图案

**头部设计**:
- **头饰**: 简化版的法老头巾(Nemes)，金蓝相间条纹
- **前额**: 眼镜蛇和鹰的图案(Uraeus)，象征保护和权威
- **皮肤**: 古铜色，符合北非人种特征

**装饰元素**:
- **胸前**: 圣甲虫(Scarab)护身符
- **手腕**: 金色手镯，刻有象形文字
- **手持物**: 纸莎草卷轴，边缘有象形文字装饰
- **腰带**: 织有埃及神明图案的布带

**象形文字元素**:
- 安卡(生命符号)
- 代表智慧的透特鸟
- 代表保护的荷鲁斯之眼
- 莲花和纸莎草图案

### 3. 中国神殿守护者 (Chinese Temple Guardian)

#### 文化背景
中国古代文明以儒家思想、道教哲学和精深的艺术成就著称。道教神仙和儒家学者都是智慧的象征。中国神殿守护者应融合仙人和学者的形象，体现东方文明的特色。

#### 设计要求
**文件名**: `temple_guardian_chinese.png`

**颜色主题**:
- **主色调**: 中国红 (#DC143C) - 象征吉祥和繁荣
- **辅助色**: 皇家金 (#FFD700) - 象征富贵和权威
- **点缀色**: 墨黑 (#000000) - 象征深邃和庄重

**服装设计**:
- **上身**: 红色道袍，宽袖设计，体现飘逸感
- **袖口**: 金色云纹刺绣，象征祥云
- **前襟**: 金色盘扣，传统中式设计
- **下摆**: 金色波浪纹装饰

**头部设计**:
- **帽子**: 黑色方帽或道冠，顶部有金色装饰珠
- **发髻**: 传统发髻造型(如果不戴帽)
- **胡须**: 长白胡须，象征仙风道骨
- **眉毛**: 浓密的白眉，增加仙人气质

**装饰元素**:
- **胸前**: 金色太极图案或八卦符号
- **腰带**: 金色丝带，打成传统结
- **手持物**: 竹简或玉册，象征知识传承
- **配饰**: 玉佩挂件，体现文人气质

**特色图案**:
- 龙纹 - 象征皇权和吉祥
- 凤纹 - 象征和谐与美德
- 云纹 - 象征飘逸和神秘
- 如意纹 - 象征吉祥如意

### 4. 亚特兰蒂斯神殿守护者 (Atlantean Temple Guardian)

#### 文化背景
亚特兰蒂斯是柏拉图描述的理想文明，以高度发达的科技和与海洋的密切联系著称。这个神秘文明应该体现先进的海洋科技和水晶能源技术。

#### 设计要求
**文件名**: `temple_guardian_atlantean.png`

**颜色主题**:
- **主色调**: 深海蓝 (#00CED1) - 象征海洋深度
- **辅助色**: 水晶绿 (#98FB98) - 象征能源科技
- **点缀色**: 珍珠白 (#F0F8FF) - 象征海洋珍宝

**服装设计**:
- **上身**: 流线型长袍，具有未来科技感
- **材质表现**: 表面应有细微的发光效果
- **装饰线**: 几何形的发光线条，模拟能源流动
- **披肩**: 半透明材质，边缘有波浪形设计

**头部设计**:
- **头冠**: 水晶制成的几何形头冠，有发光效果
- **发色**: 银蓝色，体现非人类特征
- **皮肤**: 淡蓝色调，微微发光
- **眼睛**: 发光的蓝色眼睛

**科技元素**:
- **胸前**: 发光的能源核心装置
- **手持物**: 水晶球或能源水晶
- **装饰**: 三叉戟符号，代表海洋权威
- **纹理**: 海浪和漩涡图案

**特殊效果**:
- 整体应有微弱的发光效果
- 线条应呈现能源流动感
- 颜色渐变体现深海到浅海的层次

### 5. 北欧神殿守护者 (Nordic Temple Guardian)

#### 文化背景
北欧文明以维京文化、战士传统和卢恩文字著称。北欧神话强调勇气、智慧和命运。神殿守护者应体现维京时代的智者萨满形象。

#### 设计要求
**文件名**: `temple_guardian_nordic.png`

**颜色主题**:
- **主色调**: 石灰灰 (#708090) - 象征北方的石头和冰雪
- **辅助色**: 钢铁银 (#C0C0C0) - 象征武器和工艺
- **点缀色**: 战士红 (#8B0000) - 象征勇气和血战

**服装设计**:
- **外衣**: 厚重的深灰色斗篷，抵御严寒
- **内衣**: 链甲或皮甲，体现战士传统
- **护肩**: 银色金属护肩，刻有卢恩文
- **腰带**: 宽大的皮质腰带，挂有符文饰品

**头部设计**:
- **头盔**: 装饰性的维京角盔(简化版)
- **发色**: 红色或金色，编成辫子
- **胡须**: 粗犷的红色胡须，编成小辫
- **面部**: 有战斗伤疤，体现经历

**装饰元素**:
- **臂环**: 银色螺旋臂环，维京传统
- **项链**: 雷神锤吊坠(Mjolnir)
- **手持物**: 符文石板或卢恩法杖
- **护腕**: 皮质护腕，刻有保护符文

**卢恩符文设计**:
- ᚠ (Fehu) - 财富符文
- ᚢ (Uruz) - 力量符文  
- ᚦ (Thurisaz) - 保护符文
- ᚨ (Ansuz) - 智慧符文

## 🎨 技术规范

### 文件规格
- **文件格式**: PNG (支持透明通道)
- **纹理尺寸**: 64x64像素
- **色彩深度**: 32位RGBA
- **压缩**: 无损压缩

### 存储位置
```
src/main/resources/assets/mythic_age/textures/entity/
├── temple_guardian_greek.png
├── temple_guardian_egyptian.png  
├── temple_guardian_chinese.png
├── temple_guardian_atlantean.png
└── temple_guardian_nordic.png
```

### 像素艺术标准
- **像素清晰度**: 每个像素边界清晰，无模糊
- **颜色一致性**: 使用统一的调色板风格
- **光影效果**: 符合Minecraft的光影逻辑
- **细节平衡**: 在64x64限制下平衡细节和可识别性
