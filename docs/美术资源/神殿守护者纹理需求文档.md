# 神殿守护者纹理需求文档

## 概述
本文档详细说明神话时代Mod中各文明神殿守护者的纹理设计需求。所有神殿守护者基于村民图书管理员模型，但需要不同的纹理来体现各自的文明特色。

## 技术规格
- **模型基础**：Minecraft村民图书管理员模型
- **纹理尺寸**：64x64像素
- **文件格式**：PNG格式
- **存放路径**：`src/main/resources/assets/mythic_age/textures/entity/`

## 设计原则

### 1. 文化准确性
- 每个纹理都应准确反映对应文明的服装风格
- 避免现代元素，保持古代神话风格
- 颜色选择符合文明的文化象征意义

### 2. 游戏适配性
- 纹理必须在64x64像素下清晰可辨
- 与Minecraft原版风格协调
- 在不同光照条件下都能正常显示

### 3. 功能区分
- 每个神殿守护者必须一眼就能区分文明归属
- 主要特征元素要突出明显
- 符合各自的神话背景设定

## 制作优先级

1. **希腊神殿守护者** - 优先级最高（基础系统完善）
2. **埃及神殿守护者** - 优先级高（神像系统相关）
3. **中国神殿守护者** - 优先级中等
4. **北欧神殿守护者** - 优先级中等
5. **亚特兰蒂斯神殿守护者** - 优先级较低（系统最复杂）

## 测试要求

完成纹理后需要测试：
- 在不同生物群系中的显示效果
- 与对应神殿建筑的视觉协调性
- 交易界面中的显示效果
- 日夜光照变化下的可视性
