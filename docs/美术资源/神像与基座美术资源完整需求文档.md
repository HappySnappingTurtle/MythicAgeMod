# 神话时代Mod - 神像与基座美术资源完整需求文档

## 项目背景

### 模组概述
"神话时代"是一个基于Minecraft 1.20.1 Fabric的史诗级模组，融合了五大古代文明（希腊、埃及、中国、亚特兰蒂斯、北欧）的神话元素。模组通过神殿守护者系统、神力证明交易、魔法书系统等核心功能，为玩家提供沉浸式的神话世界体验。

### 神像系统设计理念
神像系统是模组的核心视觉元素，采用多方块结构设计（4×1×1垂直结构），每个文明拥有独特的神像风格。神像不仅是装饰性建筑，更是神力证明的储存装置和文明特色的体现。

### 基座系统功能定位
基座作为神像的底座，承担着神力证明自动收集、玩家交互提取、结构完整性检测等核心功能。每个文明的基座都有独特的粒子效果和交互机制。

## 技术规格

### 多方块结构设计
- **结构类型**: 4×1×1垂直结构
- **组成**: 头部方块 + 身体方块 + 腿部方块 + 基座方块
- **总方块数**: 每个文明4个方块（3个神像 + 1个基座）
- **总纹理数**: 每个文明24个纹理（4个方块 × 6个方向）

### 纹理规格要求
- **分辨率**: 16×16像素（标准Minecraft纹理）
- **格式**: PNG格式，支持透明度
- **色彩深度**: 32位RGBA
- **文件命名**: 遵循Minecraft命名规范
