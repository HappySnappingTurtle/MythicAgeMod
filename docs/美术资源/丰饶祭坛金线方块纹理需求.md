## 闭合原理

### 转角旋转方案
通过为转角方块添加水平朝向支持，一个L形纹理可以通过旋转形成四个不同方向的转角：

```
旋转前 (north):     旋转90度 (east):    旋转180度 (south):   旋转270度 (west):
┌─                   ─┐                    ─┘                   └─  
│                      │                     │                     │
左上角                  右上角                右下角                 左下角
```

### 第一层闭合效果
俯视角看到的完整闭合效果：
```
┌─EW─EW─EW─EW─EW─EW─EW─EW─┐
NS                        NS
NS                        NS  
NS                        NS
NS                        NS
NS                        NS
NS                        NS
NS                        NS
NS                        NS
└─EW─EW─EW─EW─EW─EW─EW─EW─┘
```

## 第九、十层屋顶结构：
从玩家面对方向（南方）看：
```
第九层:     第十层:
  ^^^         ^
 /^^^\\      /^\\ 
/^^^^^\\    
```
- ^ = 屋顶脊梁（普通方块）
- / \\ = 楼梯方块（倾斜）
