# 神殿美术资源需求文档

## 项目背景

### 项目概述
**神话时代Mod (MythicAge Mod)** 是一个基于Minecraft 1.20.1的大型文明主题模组，旨在将《帝国时代：神话时代》的经典元素带入Minecraft世界。该项目通过引入多个古代文明体系，为玩家提供丰富的神话文化体验。

### 核心设计理念
- **文明多样性**：支持希腊、埃及、中国、北欧、亚特兰蒂斯五大文明体系
- **神话元素融合**：将各文明的神话传说、建筑风格、文化特色完美融入游戏
- **沉浸式体验**：通过精美的视觉设计和丰富的交互系统，创造身临其境的古代文明体验
- **模块化架构**：采用可扩展的设计架构，便于后续添加新的文明和功能

### 神殿系统的重要性
神殿作为各文明的宗教和文化中心，承载着以下重要功能：
- **文明标识**：作为各文明最具代表性的建筑，体现文明的独特风格
- **游戏机制核心**：神殿是神力系统、祭祀系统、神话单位召唤等核心玩法的载体
- **视觉焦点**：作为村庄和城市的地标建筑，需要具备强烈的视觉冲击力
- **文化传承**：通过建筑细节传达各文明的历史文化内涵

### 技术实现框架
- **NBT结构系统**：支持从NBT文件加载复杂的建筑结构
- **程序化生成**：当NBT文件不可用时，自动回退到代码生成
- **动态适配**：根据地形和环境自动调整神殿的生成位置和朝向
- **模块化组件**：神殿由多个可复用的建筑组件构成，便于维护和扩展

## 中国神殿建筑方块系统

### 已实现的方块组件

#### 1. 基础建筑方块

**中国神殿砖 (temple_chinese_bricks)**
- **材质基础**：红色陶瓦 (Red Terracotta)
- **设计特色**：采用传统中式建筑的红色陶瓦风格，体现古代宫殿建筑特色
- **物理属性**：强度1.5f，石头音效组
- **用途**：作为中国神殿建筑的主要构造方块和墙体材料
- **视觉效果**：朱红色基调，符合中国传统建筑色彩

**中国神殿台阶 (temple_chinese_stairs)**
- **材质基础**：基于中国神殿砖的台阶变体
- **设计特色**：传统庙宇阶梯设计，支持各种朝向和形状
- **物理属性**：强度1.5f，石头音效组
- **用途**：建造神殿入口台阶、屋顶结构、装饰性阶梯
- **功能特性**：完整的台阶方块功能，支持上下半部分放置

**中国神殿半砖 (temple_chinese_slab)**
- **材质基础**：基于中国神殿砖的半砖变体
- **设计特色**：用于建筑的精细装饰和层次感营造
- **物理属性**：强度1.5f，石头音效组
- **用途**：屋檐装饰、墙面分层、细节过渡
- **功能特性**：支持上半砖、下半砖、双层组合

#### 2. 装饰性建筑方块

**中国神殿柱子 (temple_chinese_pillar)**
- **材质基础**：红色陶瓦柱状方块 (PillarBlock)
- **设计特色**：传统圆柱设计，雕刻有盘龙图案
- **物理属性**：强度1.5f，石头音效组
- **用途**：神殿主体支撑结构、装饰性立柱
- **功能特性**：支持垂直放置，具有方向性纹理

**中国神殿浮雕 (temple_chinese_relief)**

- **设计特色**：雕刻有龙纹和云纹图案的装饰面板
- **物理属性**：强度1.5f，石头音效组
- **用途**：墙面装饰、文化元素展示、艺术性装饰
- **视觉效果**：精美的中式传统纹样，增强文化氛围

#### 3. 功能性方块

**中国神殿方块 (temple_chinese)**

- **功能特性**：接受中国神力证明，提供法术书兑换服务

#### 4. 多方块神像结构组件

**中国神像基座 (statue_chinese_base)**
- **材质基础**：红色陶瓦基座方块 (StatueBaseBlock)

- **功能特性**：与中国神话背景系统集成，支持交互功能

**中国神像腿部 (statue_chinese_legs)**
- **材质基础**：红色陶瓦装饰方块
- **设计特色**：仙神神像的腿部，飘逸道袍下摆
- **物理属性**：强度2.0f，石头音效组
- **用途**：4层神像结构的第二层，连接基座与身体

**中国神像身体 (statue_chinese_body)**
- **材质基础**：红色陶瓦装饰方块
- **设计特色**：仙神神像的躯干，宽袖仙袍飘逸姿态
- **物理属性**：强度2.0f，石头音效组
- **用途**：4层神像结构的第三层，展现仙神威严身姿

**中国神像头部 (statue_chinese_head)**
- **材质基础**：红色陶瓦装饰方块
- **设计特色**：仙神神像的头部，东方神仙面容
- **物理属性**：强度2.0f，石头音效组
- **用途**：4层神像结构的最顶层，完成整体神像造型

### 建筑应用指南

#### 基础结构搭建
1. **地基建设**：使用中国神殿砖作为主要地基材料
2. **墙体构造**：结合神殿砖和半砖创建层次丰富的墙面
3. **屋顶设计**：利用台阶方块构建传统中式屋顶造型
4. **支撑结构**：使用神殿柱子作为主要承重和装饰元素

#### 装饰细节处理
1. **文化元素**：通过浮雕方块展现龙纹、云纹等传统图案
2. **色彩搭配**：红色陶瓦基调体现中国传统建筑特色
3. **结构层次**：半砖和台阶的组合使用增加建筑细节
4. **功能集成**：神殿和神像方块提供游戏功能支持

### 技术规格
- **命名规范**：所有方块使用 `temple_chinese_` 或 `statue_chinese_` 前缀
- **材质一致性**：统一使用红色陶瓦 (Red Terracotta) 作为基础材质
- **强度设置**：建筑方块1.5f，神像方块2.0f
- **音效统一**：全部使用石头音效组 (BlockSoundGroup.STONE)
- **透明度**：装饰性方块设置为非完全不透明以增强视觉效果
