# 神像基座美术资源设计需求文档

## 📋 基座系统概述

神像基座是4层神像多方块结构的根基部分，位于最底层，承载整个神像的重量并展现各文明的建筑风格和文化底蕴。基座不仅是功能性的支撑结构，更是各文明艺术特色的重要体现。

### 🏗️ 基座在神像结构中的地位
- **位置**：神像多方块结构的最底层（第1层）
- **功能**：支撑整个神像结构，提供稳固根基
- **意义**：展现各文明的建筑艺术和文化特色
- **结构顺序**：基座 → 腿部 → 身体 → 头部

---

## 🎨 基座设计通用规范

### 📐 技术规格
- **纹理尺寸**：16×16像素（Minecraft标准）
- **文件格式**：PNG格式，RGBA色彩空间
- **命名规范**：`statue_{文明}_base.png`
- **存储路径**：`src/main/resources/assets/mythic_age/textures/block/`

### 🎯 设计原则
1. **稳固感**：基座应展现厚重、稳固的视觉效果
2. **文明特色**：体现各文明独特的建筑风格和装饰元素
3. **层次衔接**：与上层腿部方块在视觉上完美衔接
4. **装饰丰富**：基座是展现文明艺术细节的重要载体
5. **色彩协调**：与同文明其他神像部分保持色彩统一

### 🔍 视觉质量标准
- **清晰度**：16×16像素下细节清晰可辨
- **对比度**：确保在不同光照环境下可见
- **层次感**：通过明暗变化营造立体效果
- **装饰细节**：在有限像素内展现丰富的文化元素

## 💡 创作指导建议

### 🎨 设计创作要点
1. **文化准确性**：深入理解各文明的建筑特色和文化内涵
2. **视觉层次**：基座作为最底层，要有承载上层的视觉稳定感
3. **细节丰富**：在16×16像素限制下，合理安排装饰元素
4. **色彩统一**：确保与同文明其他神像部分色彩协调
5. **质感表现**：通过明暗对比表现不同材质的特点

### 🔍 质量检查标准
- **结构稳定感**：视觉上能够支撑整个神像
- **文化特色鲜明**：一眼就能识别出对应文明
- **装饰细节清晰**：重要文化元素清晰可辨
- **色彩搭配和谐**：符合各文明的色彩特征
- **与上层衔接**：与腿部方块在视觉上自然过渡

### 📝 制作注意事项
1. **像素精度**：每个像素都要精心设计，避免浪费
2. **对称性**：大部分基座设计需要保持对称美感
3. **立体感**：通过阴影和高光营造立体效果
4. **可读性**：重要的文化符号要清晰可读
5. **游戏适配**：确保在Minecraft环境中和谐融入
