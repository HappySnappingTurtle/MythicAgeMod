# 希腊神殿生成测试指南

## 测试目标
验证希腊类型的村庄能够正确生成希腊神殿结构，包括从NBT文件加载和代码生成的功能。

## 测试准备

### 1. 确保Mod正确安装
- 确认MythicAge Mod已正确编译并安装到Minecraft 1.20.1
- 检查游戏启动时没有相关错误日志

### 2. 准备测试世界
- 创建新的创造模式世界
- 建议使用平坦地形以便观察村庄生成

## 测试方法

### 方法一：使用命令定位村庄

1. **定位希腊村庄**
   ```
   /locate structure mythic_age:greek_village
   ```
   
2. **传送到村庄**
   ```
   /tp @s <x> <y> <z>
   ```
   其中 `<x> <y> <z>` 是上一步获得的坐标

3. **观察神殿生成**
   - 查看村庄中是否生成了希腊神殿
   - 检查神殿的结构是否完整
   - 确认神殿使用的是希腊风格的建筑元素
   - 当前代码优先加载 `mythic_age:structures/village/greek/temple_small.nbt`，失败时才回退代码生成

### 方法二：强制生成村庄

1. **使用结构方块生成**
   ```
   /give @s structure_block
   ```
   
2. **设置结构方块**
   - 放置结构方块
   - 设置模式为"加载"
   - 输入结构名称：`mythic_age:greek_village`
   - 点击"加载"按钮

### 方法三：使用调试命令

1. **直接生成神殿结构**
   ```
   /place structure mythic_age:greek_temple ~ ~ ~
   ```
   
2. **检查NBT文件加载**
   - 观察控制台日志，查看是否有NBT加载相关的信息
   - 确认没有文件读取错误

## 常见问题排查

### 问题1：神殿没有生成
**可能原因：**
- NBT文件路径错误
- 村庄生成逻辑问题
- 地形不适合生成神殿

**解决方法：**
1. 检查控制台日志中的错误信息
2. 验证NBT文件是否存在于正确路径
3. 尝试在平坦地形上测试

### 问题2：神殿结构不完整
**可能原因：**
- NBT文件损坏或不完整
- 方块注册问题
- 生成位置冲突

**解决方法：**
1. 重新生成NBT文件
2. 检查自定义方块是否正确注册
3. 调整生成位置算法

### 问题3：神殿风格不正确
**可能原因：**
- 使用了错误的NBT文件
- 代码生成逻辑错误

**解决方法：**
1. 确认NBT文件对应正确的文明类型
2. 检查代码生成的材料选择

## 日志分析

### 关键日志信息
查找以下关键词的日志信息：
- `MythicVillageProcessor`
- `generateTempleStructure`
- `loadTempleFromNBT`
- `structures/village/greek/temple_small.nbt`

### 成功日志示例
```
[INFO] MythicVillageProcessor: Successfully loaded temple from NBT: structures/village/greek/temple_small.nbt
[INFO] MythicVillageProcessor: Greek temple generated at position (x, y, z)
```

### 错误日志示例

