#### 配置文件说明

1. **结构定义** (`worldgen/structure/`):
   - 定义各神殿的基本属性和生成规则
   - 使用Jigsaw系统进行结构生成
   - 支持在村庄生物群系中生成

2. **建筑池** (`worldgen/template_pool/`):
   - 定义各文明村庄的建筑组件
   - 支持大、中、小三种规模的神殿
   - 权重控制生成概率

3. **结构集** (`worldgen/structure_set/`):
   - 控制神殿在世界中的分布
   - 埃及和中国神殿权重较高(20)
   - 亚特兰蒂斯和北欧神殿较稀有(15)

### ⚠️ 缺失的.nbt文件

**问题**: 虽然创建了配置文件，但缺少实际的.nbt结构文件
**解决方案**: 已创建`StructureGenerator.java`工具类来生成神殿结构

### ✅ v1验收口径

本轮收尾版本以代码生成神殿和神殿生成法术书作为主验收链路。数据包配置继续保留，但村庄自然生成所需的完整`.nbt`模板制作与权重精修暂列为后续项，不作为当前可玩版本的硬门槛。

## 🧪 测试方法

### 方法1：使用神殿生成法术书 (推荐)

#### 获取测试法术书
```bash
# 创造模式中获取神殿生成法术书
/give @p mythic_age:spellbook_generate_egyptian_temple
/give @p mythic_age:spellbook_generate_chinese_temple
/give @p mythic_age:spellbook_generate_atlantean_temple
/give @p mythic_age:spellbook_generate_nordic_temple
```

#### 使用方法
1. 手持法术书右键使用
2. 神殿将在玩家面向方向前方约12格处生成
3. 系统会显示生成位置信息
4. 自动生成对应的神殿守护者

#### 神殿特色对比

**埃及神殿** (11×7×11):
- 🏛️ 金字塔风格建筑
- 🟤 黄色砂岩材质
- 🏺 象形文字浮雕装饰
- 🛡️ 埃及神殿守护者
- 📿 埃及神像基座系统

**中国神殿** (13×8×13):
- 🏮 传统庙宇风格
- 🔴 红色陶瓦材质
- 🐉 龙纹装饰浮雕
- 🥷 中国神殿守护者
- ⛩️ 多层屋顶设计

**亚特兰蒂斯神殿** (15×6×15):
- 🌊 海洋科技风格
- 💙 海晶石材质(发光)
- 〰️ 几何水纹装饰
- 🧜 亚特兰蒂斯神殿守护者

**北欧神殿** (9×6×9):
- ⚔️ 维京战士风格

## 📝 问题反馈

### 常见问题
1. **神殿没有生成**: 检查是否在服务器端使用法术书
2. **纹理缺失**: 确认资源包加载正确
3. **守护者无法交互**: 检查实体注册是否成功
4. **法术书无冷却**: 这是测试版本的设计
