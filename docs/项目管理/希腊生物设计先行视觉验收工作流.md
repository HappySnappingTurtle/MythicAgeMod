# 希腊生物 Blockbench 视觉验收工作流

## 原则

- 本轮不做 Minecraft 真机截图验收。
- 每个生物只在 Blockbench 资产层确认：设计包、`.bbmodel`、UV、运行时贴图、贴图挂载后的正/侧/背三视图，以及贴图与模型 UV 的贴合度。
- 截图必须是单体资产预览，不允许把多个生物放在同一个游戏场景里堆叠判断。
- 如果验收失败，优先修 `.bbmodel`、UV 或贴图，不通过游戏内视角补救造型问题。

## 执行

```bash
python3 tools/greek_creature_visual_pipeline.py all
```

该命令会生成并审计：

- 设计包：`docs/美术资源/greek_creatures/design/<creature>.md`
- Blockbench 源文件：`docs/美术资源/blockbench/greek_creatures/<creature>.bbmodel`
- UV 模板：`docs/preview_assets/greek_creatures/<creature>/uv_template.png`
- 贴图贴合图：`docs/preview_assets/greek_creatures/<creature>/texture_fit.png`
- 贴图后 Blockbench 三视图：
  - `docs/preview_assets/greek_creatures/<creature>/blockbench/front.png`
  - `docs/preview_assets/greek_creatures/<creature>/blockbench/side.png`
  - `docs/preview_assets/greek_creatures/<creature>/blockbench/back.png`
- 三视图总览：`docs/preview_assets/greek_creatures/blockbench_validation_contact_sheet.png`
- 总清单：`docs/美术资源/greek_creatures/visual_manifest.json`
- 验收报告：`docs/preview_assets/greek_creatures/visual_report.json`
- 贴合度报告：`docs/preview_assets/greek_creatures/texture_fit_report.json`

只审计已有产物：

```bash
python3 tools/greek_creature_visual_pipeline.py audit
```

## Blockbench MCP

```bash
python3 tools/blockbench_visual_mcp.py
```

可用工具：

- `generate_design_gate_assets`：生成并审计设计包、`.bbmodel`、UV 模板、贴图三视图、贴合图和报告。
- `audit_design_gate`：只审计已有产物。
- `list_creatures`：列出生物与视觉产物路径。
- `get_creature_design`：读取指定生物设计包。

## 验收口径

设计包：

- 体量、轮廓、部件清单、Blockbench 层级、UV 计划、纹理细节、动画约束齐全。

Blockbench 三视图：

- 必须是正面、侧面、背面三视图。
- 三视图必须来自 `.bbmodel` 已挂载运行时 PNG 贴图后的模型预览。
- 正面检查脸、眼睛、头部/胸部关键特征。
- 侧面检查体长、尾部、翅膀、马身、多头颈部等侧向轮廓。
- 背面检查背部、尾部、翅膀、鬃毛、蛇发、后腿等背向特征。

UV 与贴图贴合：

- `.bbmodel` 中每个 cube 的 6 个 face UV 必须存在且不越界。
- 每个部件的 UV footprint 在实际 PNG 上必须有至少 90% 非透明像素。
- 每个部件的 UV footprint 不能是单色空白块，需有最少 2 种非透明颜色。
- `texture_fit.png` 必须在实际贴图上叠加部件 UV 框，便于人工复查贴合位置。

状态说明：

- `blockbench_passed_pending_human_shape_review` 表示自动检查通过，仍需要人工看三视图确认造型审美和设计意图。
- `blockbench_failed` 表示 UV、贴图或三视图产物缺失/不合格。

## 构建验收

```bash
./gradlew build
```

## 不再作为本轮验收依据

- Minecraft 游戏内截图。
- `run/screenshots/visual_probe_*.png`。
- 多生物同场景截图。
- 旧的 `three_quarter.png` 预览。

这些旧产物即使本地还存在，也不会被 `visual_report.json` 或 `visual_manifest.json` 引用。
