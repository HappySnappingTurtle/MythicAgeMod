当前项目不按“接近发布”或“百分比完成”描述。当前事实是：

- 仓库版本仍为 `0.1.0` 开发快照。

- 旧报告中任何“全部完成”“接近发布”“可开始 Beta”的判断均已作废。

## 当前 1.0 剩余重点

- 生物模型、纹理和动作需要人工视觉验收，特别是神话特征、比例、眼睛、嘴、武器、翅膀、尾部等。
- NBT 需要真实 MC 服务端存档重启探针，而不仅是源码级 round-trip 和静态 schema。
- 生物音效已有技术首版，但发布前仍需最终文明主题混音和响度/战斗可读性验收。
- 发布前仍需统一 README、玩家指南、CHANGELOG、版本号和 release checklist。
