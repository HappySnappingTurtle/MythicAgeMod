## 4. 后续开发优先级

### P0：保持仓库和提交卫生

- 开工前确认 `git status --short --branch`。
- 提交前确认没有本地产物和敏感信息。
- 推送前确认 remote 仍为 `git@github.com:HappySnappingTurtle/MythicAgeMod.git`。

### P1：对首批希腊神话生物做质量收口

- 平衡血量、伤害、技能冷却、生成权重和召唤成本。
- 检查动画状态切换是否和攻击/受击/死亡逻辑一致。
- 检查音效事件是否和实体行为一一对应。
- 补充面向玩家的说明文案和测试指南。

- 接入实体注册、属性、自然生成、渲染、模型层、刷怪蛋、语言项、音效、神殿守护者兑换与交易冷却。
