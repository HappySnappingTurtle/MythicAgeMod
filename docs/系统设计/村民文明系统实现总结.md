# 村民文明系统实现总结

## 概述

本项目成功实现了为原版村民添加文明属性和AI行为的系统，**不创建新的实体类型**，而是通过Mixin技术直接增强原版`VillagerEntity`的功能。

## 核心功能

### 1. 文明村民实体 (CivilizedVillagerEntity)

**文件位置**: `src/main/java/com/example/mythic_age/entity/CivilizedVillagerEntity.java`

**主要特性**:
- 继承自VillagerEntity，保持原版村民的所有功能
- 添加文明属性 (civilization)，支持5种文明类型
- 希腊文明村民具有朝圣AI，会定期前往神殿
- 完整的数据保存和加载系统

**AI行为**:
- 希腊村民：每5分钟有30%概率前往最近的希腊神殿朝圣
- 其他文明：保留原版村民行为，为未来扩展预留接口

### 2. 神力证明生成管理器 (CertificateGenerationManager)

**文件位置**: `src/main/java/com/example/mythic_age/system/CertificateGenerationManager.java`

**核心机制**:
- **阶梯式生成**: 根据神殿附近希腊村民数量，按阶梯生成神力证明
- **生成配置**:
  - 1名村民: 1个神力证明
  - 3名村民: 2个神力证明
  - 5名村民: 3个神力证明
  - 8名村民: 5个神力证明
  - 12名村民: 7个神力证明
  - 16名村民: 10个神力证明
  - 20名村民: 15个神力证明

**技术特性**:
- 每5分钟检测一次神殿附近的希腊村民
- 自动将生成的神力证明存储到最近的希腊神像基座
- 支持玩家通过潜行右键提取神力证明
- 完整的通知和音效系统

### 3. 村民生成拦截系统 (VillagerSpawnMixin)

**文件位置**: `src/main/java/com/example/mythic_age/mixin/VillagerSpawnMixin.java`

**功能**:
- 使用Mixin技术拦截原版村民生成
- 自动检测村庄的文明类型
- 将普通村民替换为对应文明的文明村民
- 保持原村民的所有属性和数据

**检测机制**:
- 搜索64格范围内的神殿或神像基座方块
- 根据方块名称判断文明类型
- 支持5种文明的自动识别

### 4. 神像基座交互升级

**修改文件**: `src/main/java/com/example/mythic_age/block/StatueBaseBlock.java`

**新增功能**:
- **潜行右键**: 提取存储的神力证明
- **普通右键**: 显示详细信息和状态
- 完整的音效和消息反馈系统

## 实体注册系统

### 1. 服务器端注册

**文件**: `src/main/java/com/example/mythic_age/entity/ModEntities.java`

- 注册CIVILIZED_VILLAGER实体类型
- 配置实体属性和碰撞箱
- 集成到现有的实体注册流程

### 2. 客户端渲染

**文件**: `src/main/java/com/example/mythic_age/MythicAgeModClient.java`

- 使用原版村民渲染器
- 保持视觉一致性
- 无需额外的模型或纹理资源

## 技术实现亮点

### 1. 智能文明检测
- 自动识别村庄文明类型
- 无需手动配置或标记
- 支持多种神话建筑的识别

### 2. 阶梯式奖励机制
- 鼓励玩家建设大型村庄
- 平衡的奖励递增曲线
- 可配置的生成参数

### 3. 无缝集成
- 完全兼容原版村民系统
- 不影响现有的交易和繁殖机制
- 保持Mod的整体架构一致性

### 4. 扩展性设计
- 预留其他文明的AI接口
- 支持未来添加更多文明特性
- 模块化的代码结构

## 游戏体验

### 玩家收益
1. **自动化神力证明生成**: 无需手动操作，村民自动贡献
2. **规模化奖励**: 村庄规模越大，收益越高
3. **文明特色**: 不同文明村民展现独特行为
4. **便捷提取**: 简单的交互方式获取奖励

### 平衡性考虑
1. **时间限制**: 5分钟生成间隔防止过度刷取
2. **距离限制**: 32格神殿影响范围
3. **阶梯递增**: 避免线性增长导致的平衡问题
4. **文明限制**: 目前仅希腊文明参与生成
