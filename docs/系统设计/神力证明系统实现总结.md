# 神力证明系统实现总结

## 📋 项目概述

本次开发实现了《神话时代 Mod》的核心神力证明系统，为不同神话文明提供了独特的神力证明获取方式，增强了游戏的策略性和文化沉浸感。

## 🎯 实现的功能

### 1. 核心管理系统
- **GodPowerCertificateManager**: 单例模式管理器，统一处理所有神力证明相关逻辑
- **渐进式解锁机制**: 玩家需要与神殿守护者对话才能开启神力证明收集功能
- **数据持久化**: NBT数据保存和加载，支持世界重启后数据保持

### 2. 多文明获取方式

#### 希腊文明：贸易兑换
- **实现方式**: 与希腊神殿守护者用矿物/贵重物品兑换
- **兑换比率**:
  - 钻石系列: ×3 倍率 (1钻石 = 3证明)
  - 金系列: ×2 倍率 (1金锭 = 2证明)
  - 铁系列: ×1 倍率 (1铁锭 = 1证明)  
  - 绿宝石: ×5 倍率 (1绿宝石 = 5证明)
  - 下界合金: ×5 倍率 (1下界合金 = 5证明)
- **特点**: 立即交易，适合前期快速获得

#### 埃及文明：神像基座系统
- **实现方式**: 神像基座周期性自动产出
- **核心组件**:
  - `EgyptianStatuePedestalBlock`: 神像基座方块
  - `EgyptianStatuePedestalBlockEntity`: 方块实体，处理产出逻辑
- **神像等级系统** (7个等级):
  1. 奴隶神像: 1个/2分钟 (成本: 5金锭)
  2. 市民神像: 2个/2分钟 (成本: 10金锭)
  3. 士兵神像: 3个/2分钟 (成本: 20金锭)
  4. 王后神像: 5个/1.5分钟 (成本: 35金锭)
  5. 国王神像: 7个/1.5分钟 (成本: 50金锭)
  6. 王室夫妇神像: 12个/1分钟 (成本: 80金锭)
  7. 法老神像: 20个/1分钟 (成本: 120金锭)
- **特点**: 持续产出，适合长期收益投资

#### 北欧文明：战斗掉落
- **实现方式**: 击杀怪物有概率掉落
- **掉落机制**:
  - 普通怪物 (僵尸、骷髅): 5% 概率, 1个
  - 中等怪物 (爬行者、蜘蛛): 8% 概率, 1个
  - 稀有怪物 (末影人、女巫): 15% 概率, 2个
  - 精英怪物 (凋灵骷髅、烈焰人): 20% 概率, 3个
  - BOSS级怪物:
    - 凋灵: 100% 概率, 30个
    - 末影龙: 100% 概率, 50个
- **特点**: 通过战斗获得，风险与收益并存

#### 中国文明：人口繁荣
- **实现方式**: 基于村庄人口数量周期性产出
- **产出机制**:
  - 基础产出: 每20个村民产出1个证明/分钟
  - 概率奖励: 剩余人口提供额外概率 (剩余人口×5%)
- **示例**:
  - 25村民 = 1个固定 + 25%概率额外1个
  - 50村民 = 2个固定 + 50%概率额外1个
  - 100村民 = 5个固定/分钟
- **特点**: 鼓励村庄发展和保护

### 3. 神殿守护者系统
- **TempleGuardianEntity增强**: 添加了完整的对话和交易系统
- **多文明支持**: 可设置不同文明类型，提供对应服务
- **交互功能**:
  - 开启神力证明收集功能
  - 显示兑换菜单和价格
  - 处理各种交易逻辑
  - 提供游戏指导信息

## 📚 技术实现特点

### 1. 设计模式
- **单例模式**: GodPowerCertificateManager使用单例模式，确保全局一致性
- **工厂模式**: 不同文明的获取方式通过枚举和工厂方法管理
- **观察者模式**: 通过事件系统集成到游戏循环中

### 2. 数据结构
- **EgyptianStatueType枚举**: 管理7个等级神像的属性
- **HashMap缓存**: 高效管理玩家数据和基座数据
- **NBT序列化**: 完整的数据持久化支持

### 3. 性能优化
- **Tick优化**: 埃及基座每tick检查，但只在到达间隔时产出
- **批量处理**: 北欧掉落和中国人口系统支持批量处理
- **内存管理**: 自动清理无效的基座数据
