# 神力系统设计与实现方案

## 项目概述

本文档详细规划了神话时代Mod中中国文明、北欧文明、埃及文明相关神力的设计和实现方案，基于微软《神话时代：重制版》(Age of Mythology: Retold)的游戏机制和设定，包括神力效果设计、美术资源需求和国际化处理。

### 设计原则
- **忠实原作**：严格遵循《神话时代：重制版》的神力系统设计理念
- **文明特色**：体现各文明独特的神话背景和文化特征
- **游戏平衡**：确保新增神力与原版神力在强度和实用性上保持平衡
- **视觉一致**：美术风格与原版游戏保持一致性

### 1.3 中国神力证明获取机制
- **基础机制**：基于村庄人口数量周期性产出
- **产出公式**：每10分钟产出 = max(1, 村庄人口数 / 5)
- **最大产出**：每次最多产出5个证明
- **特殊加成**：
  - 村庄有铁傀儡：产出+1
  - 村庄有猫：产出+1
  - 玩家声望高：产出+50%

### 4.2 纹理设计总体指导原则

**通用设计标准**:
- **分辨率**: 所有纹理文件统一使用 16x16 像素，符合 Minecraft 原版风格
- **文件格式**: PNG 格式，支持透明度
- **色彩深度**: 24位真彩色 + 8位透明通道
- **风格一致性**: 保持像素艺术风格，避免过于复杂的细节

**文明特色设计原则**:
- **中国文明**: 采用传统中国色彩搭配（红、金、蓝、绿），融入龙、凤、太极等传统元素
- **北欧文明**: 使用冷色调为主（蓝、灰、白），结合符文、动物图腾等北欧元素
- **埃及文明**: 以暖色调为主（金、黄、红），融入象形文字、神祇形象等埃及元素

**法术书封面结构**:
1. **背景底色**: 根据文明特色选择主色调
2. **边框装饰**: 文明特色纹样边框
3. **中心图案**: 神力相关的核心符号或图像
4. **细节装饰**: 小型装饰元素增强视觉效果

**设计质量要求**:
- **可识别性**: 在游戏界面中能够清晰识别不同神力
- **美观性**: 符合游戏整体美术风格
- **文化准确性**: 尊重各文明的文化特色和宗教背景
- **游戏适配性**: 在不同光照条件下都能保持良好的视觉效果
