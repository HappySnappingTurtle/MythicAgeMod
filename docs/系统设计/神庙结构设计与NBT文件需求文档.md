# 神庙结构设计与NBT文件需求文档

## 项目概述

神话时代Mod需要为四个主要文明创建独特的神庙结构，每个神庙都需要有对应的.nbt（命名二进制标签）文件用于世界生成。本文档详细说明了每个神庙的设计要求、建筑风格、使用的方块类型以及生成配置。

## 技术规格

### NBT文件基本要求

- **文件格式**：.nbt (Minecraft结构文件)
- **存储位置**：`src/main/resources/data/mythic_age/structures/village/`
- **命名规范**：`{civilization}_temple_{size}.nbt`
- **支持规模**：小型(small)、中型(medium)、大型(large)

### 通用技术标准

- **最大尺寸**：25×25×15 方块 (防止性能问题)
- **最小尺寸**：9×9×6 方块 (保证功能完整性)
- **地基深度**：2-3层 (确保稳定生成)
- **入口朝向**：支持4个方向旋转
- **兼容性**：适配所有村庄生物群系

## 文明-神庙设计详细说明

### 1. 埃及神庙 (Egyptian Temple)

**设计风格：金字塔与神殿融合**

- **建筑特色**：阶梯金字塔、方尖碑、狮身人面像元素
- **色彩主题**：沙漠黄、金色装饰、蓝色天青石点缀
- **尺寸规格**：
  - 小型：11×7×9 (村庄神龛)
  - 中型：15×9×11 (标准神庙)  
  - 大型：21×11×13 (法老陵墓)

**必需方块类型：**

```
核心结构方块：
- temple_egyptian_bricks (埃及神殿砖) - 主体建筑材料
- temple_egyptian_stairs (埃及神殿台阶) - 楼梯和装饰
- temple_egyptian_slab (埃及神殿半砖) - 细节装饰
- temple_egyptian_pillar (埃及神殿柱子) - 支撑柱
- temple_egyptian_relief (埃及神殿浮雕) - 墙面装饰

功能方块：
- egyptian_statue_pedestal (埃及神像基座) - 1-2个
- relic_pedestal (圣物基座) - 1个
- 守护者生成点标记方块 - 1个

装饰方块：
- minecraft:sandstone (沙石) - 地基
- minecraft:chiseled_sandstone (錾制沙石) - 装饰
- minecraft:gold_block (金块) - 贵重装饰
- minecraft:lapis_block (青金石块) - 颜色点缀
```

**特殊特征：**

- 入口设计有狮身人面像风格的柱子
- 内部有阶梯式的祭坛区域
- 顶部有小型金字塔装饰
- 墙面有象形文字风格的浮雕

## 实现优先级与时间规划

### 阶段一：基础模型创建 (1-2天)

1. **方块模型文件**：创建所有20个神殿建筑方块的JSON模型
2. **物品模型文件**：创建对应的物品模型引用
3. **基础纹理**：创建占位纹理文件(可以先用希腊神殿的纹理作为模板)

### 阶段二：纹理资源制作 (3-5天)

1. **埃及风格纹理**：沙漠黄色调，金色装饰线条
2. **中国风格纹理**：朱红色调，金色边框，龙纹装饰
3. **亚特兰蒂斯纹理**：青蓝色调，发光效果，几何图案
4. **北欧风格纹理**：深灰色调，粗糙质感，符文装饰

### 阶段三：结构设计与生成 (2-3天)

1. **使用结构生成器**：通过`StructureGenerator.java`创建基础结构
2. **手动调整优化**：在游戏中精细化设计每个神庙
3. **导出NBT文件**：保存完整的结构到NBT文件
4. **测试与调试**：确保生成正常且美观

### 阶段四：集成测试 (1天)

1. **村庄生成测试**：验证神庙能正确生成在村庄中
2. **守护者集成**：确保守护者能正确生成在神庙中
3. **功能验证**：测试圣物基座、神像基座等功能方块
4. **性能优化**：确保生成不会造成延迟

## 技术实现注意事项

### 数据包配置

- **结构定义**：在`worldgen/structure/`中定义生成规则
- **模板池**：在`template_pool/village/`中配置村庄集成
- **权重平衡**：确保各文明神庙生成概率合理

### 性能考虑

- **结构大小**：避免过大的建筑影响生成速度
- **方块数量**：合理控制特殊方块的使用数量
- **生成频率**：避免过于密集的神庙生成
