# 神殿守护者交易系统升级需求文档

## 问题描述

### 现状分析
当前神殿守护者交易系统存在严重故障：
- **交易数量严重受限**：代码中定义了13个希腊法术书交易，但实际只显示2个
- **系统底层冲突**：使用VillagerEntity导致与原版交易系统冲突
- **扩展性差**：难以添加新的交易类型和自定义逻辑

### 技术问题根源
1. **Minecraft原版限制**：VillagerEntity的交易系统有内置的数量和类型限制
2. **职业冲突**：图书管理员职业与自定义交易逻辑冲突
3. **代码架构问题**：过度依赖原版村民系统，缺乏灵活性

## 解决方案对比

### 方案一：修复现有系统 ❌
**优点**：工作量小，保持兼容性
**缺点**：仍受原版限制，扩展性差
**状态**：已尝试，效果有限

### 方案二：创建自定义实体 ✅ **已完成**
**优点**：完全可控，无原版限制，易扩展
**缺点**：工作量较大，需要完整实现
**状态**：**已完成实施**
